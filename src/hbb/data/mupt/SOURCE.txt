Which of the two cvmfs files
----------------------------
Each 2026-06-18 directory also contains muon_scalesmearing_VXBS.json.gz, the
vertex/beam-spot-constrained variant, meant for Muon_bsConstrainedPt.  We use the
nominal muon_scalesmearing.json.gz because correct_muons() feeds standard Muon_pt.

What changed vs. the previous vendored version
----------------------------------------------
The files replaced here dated from the 2025-08-14 snapshots (2022/2023) and the
2025-10-17 = 2025-11-27 snapshot (2024); all corrections were "version": 1.
The 2026-06-18 files carry "version": 2 with updated parameter values and add an
extra correction, "RandomSmearing" (evtNr, lumiNr, phi -> random number).
src/hbb/MuonScaRe.py generates that random number itself and does not read the new
correction; all correction names, input names/types/order and variation keys
("nom"/"stat"/"syst"/"rho_stat"/"rho_syst") used by MuonScaRe.py are unchanged, so
the swap is drop-in and only shifts the corrected pT values (sub-percent).
